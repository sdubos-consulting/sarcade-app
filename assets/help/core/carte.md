# Carte

## Le haut de l'écran

- Le **crayon** ouvre les outils de dessin.
- La barre **Rechercher** trouve un opérateur, un point, un dessin, des coordonnées ou une adresse. Le résultat choisi reçoit une épingle rouge ; touchez-la pour ouvrir le menu du point. Hors connexion, les adresses ne sont pas trouvées.
- La **pastille de droite** donne la météo et l'état de la liaison :
  - toucher le point de liaison ouvre le Diagnostic ;
  - toucher la météo ouvre la page Météo ;
  - un **appui long** passe en **mode rouge** (pour la nuit) ; un autre appui long le quitte.
- Si le serveur ne répond plus depuis 2 minutes, l'heure des dernières données est affichée.

## Les boutons de droite

- **Fond et affichage** : le fond de carte, le thème et les calques (voir plus bas).
- **Ma position** : chaque toucher passe au mode suivant :
  1. centré sur moi ;
  2. suivi, nord en haut ;
  3. boussole : la carte tourne avec le téléphone ;
  4. tous les opérateurs dans le cadre.
- **Écrans** : apparaît quand un écran de TV est autorisé.
- **SOS** : voir la rubrique « SOS et alertes ».

Sans boussole, le cap de route remplace le mode boussole. Faire glisser la carte arrête le suivi. Quand la carte est tournée, le bouton **N** remet le nord en haut.

Votre position est le point bleu ; il devient gris quand la position est perdue.

## Toucher la carte

- **Toucher un opérateur** affiche sa trace et ouvre sa fiche : vitesse, cap, altitude, âge de la position, favori, **Discuter**, statut, trace sur 1 h, 6 h ou 24 h. Un second toucher retire la trace.
- **Toucher un cercle numéroté** zoome sur le groupe.
- **Toucher un endroit vide** ferme ce qui est ouvert.
- **Appui long** (ou clic droit) ouvre le **menu du point** :
  - les coordonnées et le nom du lieu, avec **Copier** ; toucher la ligne ouvre « Infos du point » (copier, envoyer en message, lecture radio, grands caractères) ;
  - **Point d'intérêt**, **Envoyer une équipe** (PCO), **Mesurer**, **Y aller**, **Météo**, **Sélectionner une zone**.

## Dessiner

Touchez le crayon. Outils : Ligne, Flèche, Cercle, Rectangle, Zone, Libre, Texte, avec **Annuler** et **Rétablir**.

- Pour une ligne ou une zone, touchez les points du tracé, puis ✓ **Terminer** ; ⌫ retire le dernier point.
- Un objet sélectionné peut changer de couleur, d'épaisseur, de transparence, de nom ; on peut le **Dupliquer** ou le **Supprimer**.
- Le PCO peut activer le **Géorepérage** sur une forme fermée.
- **Sélection** : touchez plusieurs objets, ou appui long puis glisser pour un rectangle. Seulement vos objets, sauf pour le PCO.
- Double toucher sur un objet pour le renommer.

L'import et l'export de fichiers sont dans **Outils › Fichiers**.

## Points d'intérêt

- Créez-en un par l'appui long, puis **Point d'intérêt** : nom, icône, couleur.
- Toucher un point ouvre sa fiche : **Modifier**, **Déplacer**, **Envoyer en message**, **Itinéraire jusqu'ici**, **Supprimer**.
- Modifier, déplacer et supprimer sont réservés à l'auteur et au PCO. La suppression vaut pour tous et est inscrite dans la main courante.

## Mesurer

**Mesurer** (menu du point) donne la distance, l'azimut vrai et magnétique, et une flèche d'orientation sur téléphone.

- Le menu permet de choisir l'origine (ma position, un point, un autre opérateur), la déclinaison et le format des coordonnées.
- **Plus de formats** : DMS, UTM, MGRS, QTH, Lambert 93, DFCI, chacun avec un bouton pour copier.
- **Ouvrir dans…** ouvre le point dans une autre application (Waze, Google Maps, Organic Maps, OsmAnd, Plans…, selon l'appareil). Cochez « Toujours ouvrir avec cette application » pour ne plus avoir à choisir ; le choix se change dans Paramètres › Cet appareil.

## Y aller et itinéraires

- **Y aller** propose de naviguer dans l'application, de créer un itinéraire ou d'ouvrir une autre application.
- La navigation se fait en voiture, à pied, en tout-terrain ou en ligne droite.
- Sans serveur, l'itinéraire peut être calculé sur l'appareil si les routes ont été téléchargées (« Télécharger les routes sur l'appareil »).
- Les itinéraires se gèrent dans **Outils › Itinéraires**.

## Fond et affichage

- **Fond de carte** : touchez-le pour choisir un autre fond.
- **Garder sur ce téléphone** (application Android et iPhone) : garde la carte pour le hors connexion.
- **Thème** : Jour, Nuit, Auto, Rouge.
- **Calques** : opérateurs, dessins, points d'intérêt, ordres, traces, pluie (radar). Toucher le nom d'un calque règle sa transparence.

## Météo

La page **Météo** donne la prévision du lieu. Hors connexion, la dernière prévision gardée est montrée avec sa date. Le PCO peut la **Diffuser**.
