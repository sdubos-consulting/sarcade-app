# TV

La carte de l'événement peut s'afficher sur une Smart TV.

## Relier une TV

1. Sur la TV, ouvrez **tv.sarcade.org** : un QR code et un code s'affichent.
2. Dans l'application, **Outils › Afficher sur une TV**.
3. **Scanner le QR code** (Android et iPhone), ou **Saisir le code** (6 caractères).
4. Donnez un nom à l'écran. La TV affiche l'événement.

Une TV sur le même réseau peut aussi demander à se connecter : l'application propose **Autoriser** ou **Ignorer**. Cette découverte se coupe dans le même écran.

## Piloter l'écran

Pour chaque écran relié :

- **Envoyer ma vue** : la TV prend votre centre, votre zoom, votre fond de carte et vos calques ; vous pouvez y ajouter la colonne des messages ;
- **Identifier** : le nom de l'écran s'affiche en grand 5 secondes ;
- **Mode de l'écran** : Jour, Nuit ou Automatique ;
- **Messages** : afficher ou masquer ;
- **Retirer le bandeau SOS** : la personne qui a relié l'écran ou un administrateur ;
- menu **⋮** : **Renommer**, **Revenir à la vue par défaut**, **Révoquer**.

Une fois un écran relié, le bouton **Écrans** apparaît sur la carte : il envoie votre vue en un toucher et peut faire suivre votre vue à la TV.
