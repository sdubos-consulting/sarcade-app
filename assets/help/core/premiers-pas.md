# Premiers pas

## Le premier lancement

Sur téléphone et sur le web, l'application demande d'abord trois informations :

1. **Serveur** : l'adresse donnée par le PCO, par exemple https://app.sarcade.org ou une adresse locale comme http://192.168.0.110:8000.
2. **Événement** : choisissez-le dans la liste. S'il n'y a qu'un seul événement ouvert, il est choisi tout seul. Le bouton de rechargement relit la liste.
3. **Identifiant du terminal** : un nom unique par opérateur (par exemple TERRAIN-01). Les autres le voient sur la carte.

Touchez ensuite **Enregistrer**.

Si le serveur est protégé, la ligne « Connexion requise » apparaît : touchez **Se connecter** et suivez la page de connexion (adresse e-mail, puis code reçu par e-mail). Sur ordinateur et sur le web, la page de connexion s'ouvre à part : copiez le jeton affiché, collez-le dans « Jeton de connexion », puis **Valider**.

Sans réseau, la dernière liste d'événements connue est proposée.

## Le choix de l'événement à chaque démarrage

- Un seul événement ouvert : il est suivi sans question.
- Plusieurs : la fenêtre « Choisir l'événement » les liste, les actifs d'abord, puis les brouillons.
- Aucun : l'application le dit ; le PCO peut en créer un.
- Un événement choisi à la main n'est jamais remplacé tant que le serveur le connaît.

## Changer d'événement ou de serveur

**Paramètres › Cet appareil** :

- **Serveur** : la liste des serveurs déjà utilisés ; on peut en ajouter, en renommer, en oublier.
- **Événement suivi** : la liste des événements du serveur.
- **Nom de l'appareil** : le nom vu par les autres participants.

Chaque changement est confirmé. Si des éléments attendent encore d'être envoyés, l'application propose **Envoyer d'abord**, **Garder pour plus tard** ou **Annuler**.

Le PCO crée un événement avec le bouton **+** à côté de l'événement : nom et modèle (Exercice, SATER, Mission réelle, Course, Famille, Amis).

## Votre profil

Touchez votre nom en haut de **Paramètres** pour ouvrir **Mon profil** :

- **Compte SARCADE** : se connecter avec son adresse e-mail et un code reçu par e-mail. Une fois connecté, **Mes appareils** liste vos appareils, qu'on peut révoquer.
- **Indicatif** : facultatif, par exemple F4ABC-7.
- **Couleur de dessin** : pour vos nouveaux dessins ; les anciens gardent la leur.
- **Icône sur la carte** : vos initiales, ou une icône (à pied, vélo, voiture, ambulance, bateau, PCO…).
- **Photo** : à la place des initiales, vue seulement des participants de l'événement.
- **Langue de l'application** : langue de l'appareil, français ou anglais.

Chaque réglage s'applique tout de suite.

## Se repérer dans l'application

Sur téléphone, la barre du bas donne **Carte**, **Messages**, **Équipes**, **Outils** et **Paramètres**.

- Toucher de nouveau un onglet revient au début de sa liste ou ferme l'écran ouvert dedans.
- La touche Retour d'Android revient d'abord à la carte.
- Un **point rouge** sur Paramètres signale un problème : Paramètres s'ouvre alors sur Diagnostic.

Sur ordinateur, ces onglets sont dans une colonne à gauche, avec des outils épinglés (6 au plus). Clic droit sur un outil épinglé pour le retirer ou organiser la colonne.

Certaines fonctions n'apparaissent que si un module est actif pour l'événement : leur aide est en bas de la page Aide, dans « Modules ».
