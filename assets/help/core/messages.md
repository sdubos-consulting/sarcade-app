# Messages

## La liste des conversations

- En tête, **Tous** (tous les participants de l'événement), puis les groupes, puis les conversations privées. Les favoris passent d'abord, puis les non lues.
- **Rechercher** trouve une conversation, ou une personne à qui écrire un premier message.
- Un **appui long** sur une conversation l'ajoute aux favoris ou l'en retire.
- **Nouveau groupe** crée un groupe ; le menu **Plus** donne les **Messages importants** de toutes vos conversations.

Sur téléphone, une conversation s'ouvre en plein écran ; la flèche revient à la liste. Sur un grand écran, la liste et la conversation sont côte à côte.

## Écrire

- Tapez dans le champ **Message**. Sur ordinateur, Entrée envoie ; Maj+Entrée va à la ligne.
- Le bouton **+** donne :
  - les **Messages prédéfinis** (un toucher envoie) ;
  - **Envoyer une photo** ;
  - la **priorité** : Routine, **Urgent** (orange) ou **Immédiat** (rouge). Toucher la pastille de priorité revient à Routine.
- Le micro **Dicter** remplit le champ par la voix ; rien n'est envoyé sans vous. Sur Windows, utilisez la dictée de Windows (touches Windows + H).
- Tapez **@** pour mentionner quelqu'un.
- Une image copiée peut être collée (Ctrl+V, ou « Coller une image »).

## Photos

- Sur téléphone : **Prendre une photo** ou **Choisir une image** ; sur ordinateur, choisissez un fichier.
- Ajoutez une légende si besoin, puis **Envoyer la photo**. 10 Mo au maximum.
- Seules les images s'envoient dans Messages ; les autres fichiers sont dans **Outils › Fichiers**.
- Touchez une photo pour l'agrandir et l'**Enregistrer**.

## Suivre un message

Les coches de vos messages : en attente d'envoi, **Envoyé**, **Reçu**, **Lu** (en bleu). Dans un groupe, touchez le compteur pour voir qui a reçu et lu.

Un message **Immédiat** reçu garde les boutons **Accepter** et **Refuser** jusqu'à votre réponse.

## Agir sur un message

Touchez une bulle (ou appui long, ou clic droit) :

- réactions, **Répondre** (ou glisser la bulle vers la droite), **Répondre en privé** ;
- accusés : Reçu, Lu, Accepté, Refusé ;
- **Copier**, **Transférer**, **Important** ;
- **Modifier** : l'auteur, pendant 15 minutes ;
- **Supprimer** : pour moi, toujours ; **pour tous**, l'auteur pendant 2 jours, le PCO à tout moment. Les détresses et les ordres ne sont jamais supprimés pour tous.

## Menu de la conversation

Le bouton **⋮** donne :

- **Chercher dans la conversation** ;
- **Exporter en PDF** (tout, aujourd'hui, ou une période) ;
- la **sourdine** : 8 h, 1 semaine ou toujours. Les détresses, les messages Immédiat, les ordres et les mentions sonnent quand même.

## Groupes

- Tout le monde peut créer un groupe et en devient responsable. Seuls les responsables et le PCO le modifient.
- Réglages : nom, description, membres, couleur, canal radio associé.
- **Écoute seule** : seuls les émetteurs désignés, les responsables et le PCO écrivent.
- Un groupe **archivé** ne reçoit plus de messages.

## Canal vocal

Si le serveur propose la voix, un casque apparaît en haut de la conversation (**Tous** ou un groupe) : **Rejoindre le canal vocal**. Maintenez le micro pour parler. La voix n'est pas enregistrée.

## Lecture à voix haute

Dans **Paramètres › Notifications**, « Lire les messages à voix haute » : Jamais, **En voiture** (par défaut) ou Toujours. Par défaut, seuls les messages Urgent, Immédiat et les détresses sont lus.
